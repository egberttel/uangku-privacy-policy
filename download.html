⚙️ Cara Install

1
Download APK di atas (pilih arm64 untuk HP modern)
2
Buka Pengaturan → Keamanan → Install aplikasi tidak dikenal → aktifkan untuk browser kamu
3
Buka file APK yang sudah didownload → tap Install
4
Buka app UangKu → daftar akun baru
