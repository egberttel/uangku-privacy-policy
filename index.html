1. Tentang Kebijakan Ini

Kebijakan Privasi ini menjelaskan bagaimana aplikasi UangKu – Pencatatan Keuangan ("aplikasi", "kami") mengumpulkan, menggunakan, menyimpan, dan melindungi data Anda. Dengan menggunakan UangKu, Anda menyetujui kebijakan ini.

UangKu dibuat oleh Egbert Telaumbanua sebagai aplikasi pencatatan keuangan pribadi. Aplikasi ini tidak berafiliasi dengan lembaga keuangan mana pun.

2. Data yang Kami Kumpulkan

Jenis DataContohDisimpan Di
Data Akun Nama, alamat email, kata sandi (di-hash) Server kami (terenkripsi)
Data Keuangan Transaksi, kategori, dompet, anggaran, tabungan, investasi, tagihan Perangkat Anda (AES-256) & server kami
Data Preferensi Pengaturan tampilan, preferensi notifikasi Perangkat Anda saja
Data Keamanan Kunci biometrik (sidik jari/wajah), PIN aplikasi Perangkat Anda saja (Keystore Android)

Yang TIDAK kami kumpulkan: lokasi GPS, kontak telepon, data kamera, nomor kartu kredit/rekening bank, maupun data iklan/tracking.

3. Cara Kami Menggunakan Data

  • Menyediakan dan menyinkronkan fitur pencatatan keuangan antar perangkat
  • Mengirim notifikasi pengingat tagihan dan anggaran yang Anda aktifkan sendiri
  • Mengamankan akun Anda melalui autentikasi email dan biometrik
  • Menampilkan ringkasan dan analisis keuangan pribadi Anda

Kami tidak menjual, menyewakan, atau berbagi data Anda kepada pihak ketiga untuk tujuan pemasaran.

4. Keamanan Data Penting

Kami menerapkan beberapa lapisan keamanan:

  • Enkripsi lokal: Database di perangkat Anda dienkripsi dengan AES-256 (SQLCipher)
  • Enkripsi transit: Semua komunikasi menggunakan HTTPS dengan certificate pinning
  • Penyimpanan token: Token autentikasi disimpan di Android Keystore (tidak bisa diekstrak)
  • Biometrik: Data sidik jari/wajah tidak pernah meninggalkan perangkat Anda

5. Izin Aplikasi

IzinAlasan

POST_NOTIFICATIONS Mengirim pengingat tagihan dan anggaran (opsional, bisa dimatikan)
RECEIVE_BOOT_COMPLETED Memulihkan jadwal notifikasi setelah perangkat restart
USE_BIOMETRIC Kunci aplikasi dengan sidik jari atau wajah (opsional)

6. Penyimpanan & Retensi Data

  • Data lokal tersimpan di perangkat Anda selama aplikasi terpasang
  • Data server disimpan selama akun Anda aktif
  • Jika Anda menghapus akun, semua data di server dihapus dalam 30 hari
  • Menghapus aplikasi akan menghapus semua data lokal secara otomatis

7. Hak Anda

Anda berhak untuk:

  • Mengakses semua data yang tersimpan di akun Anda
  • Mengekspor data keuangan Anda kapan saja
  • Menghapus akun beserta seluruh data Anda
  • Menonaktifkan notifikasi dan biometrik kapan saja dari Pengaturan

Untuk menghapus akun, buka Pengaturan → Hapus Akun di dalam aplikasi.

8. Anak-Anak

UangKu tidak ditujukan untuk pengguna di bawah 13 tahun. Kami tidak secara sadar mengumpulkan data dari anak-anak. Jika Anda mengetahui adanya penggunaan oleh anak di bawah 13 tahun, harap hubungi kami.

9. Perubahan Kebijakan

Jika kebijakan ini berubah, kami akan memberi tahu melalui notifikasi di dalam aplikasi setidaknya 7 hari sebelum perubahan berlaku. Tanggal "Berlaku mulai" di bagian atas halaman ini akan diperbarui.
